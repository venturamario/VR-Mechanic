# VR Mechanic Workshop 
VR SGI project

**VR Mechanic Workshop** is an interactive **Unity** scene for **Meta Quest 3** that places the user in a low-poly city and mechanic’s garage. It supports **continuous/teleport locomotion**, **grab & drop** interactions.  
Tech stack: **Unity 2021.3+ (URP)**, **Meta XR Core/Interaction SDK v81**, **Meta XR Simulator** (PC testing).

## Quick Start (2 steps)
1. Open the project in Unity (URP already configured).  
2. Press **Play** to test with **Meta XR Simulator** on PC, or build for **Meta Quest 3**.
